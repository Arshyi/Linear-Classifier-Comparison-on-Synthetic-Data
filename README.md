# Linear-Classifier-Comparison-on-Synthetic-Data
This project explores and compares several linear classification algorithms on a 2D synthetic dataset. The dataset consists of two circular clusters centered at (+1, 0) and (−1, 0), with adjustable radius to control linear separability.  🚀 Implemented Models Perceptron Hinge Loss SGD (SVM-style) Logistic Regression, Max-Margin Classifier (CVXPY)
